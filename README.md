# Bank in Game

Простой игровой банк для ролевых игр и игр живого действия: виртуальные деньги, роли, юрлица, переводы, такты. Без реальных платежей, карт и кредитов.

Интерфейсы:
- веб-кабинет игрока (телефон и ПК);
- Telegram-бот и Telegram Mini App;
- веб-кабинет Супер-ведущего (игры, шаблоны, ответвления) и ведущего / канцелярии с таблицами переводов, сводкой по тактам и синхронизацией с Google Sheets.

Все интерфейсы работают с одной базой, поэтому балансы и переводы везде одинаковые.

## Статус

Этап 1 готов: сервер, база, веб-кабинеты игрока, ведущего и Супер-ведущего, такты, выгрузка в Excel.
Дальше: Telegram-бот и Mini App (этап 2), синхронизация с Google Sheets (этап 3).
Архитектура, модель данных и согласованные правила — в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Стек

Node.js + TypeScript (Fastify), PostgreSQL, React + Vite. Для локального запуска и тестов используется
встроенный PostgreSQL (PGlite) — ставить базу не нужно.

## Запуск локально

Нужен Node.js 20+.

```bash
npm install
npm run seed:demo   # демо-игра «Город N»: super/super123, host/host123, коды ролей печатаются в консоль
npm run dev         # сервер http://localhost:3000, веб http://localhost:5173
```

Тесты: `npm test`.

## Продакшен

```bash
npm run build
DATABASE_URL=postgres://... SUPER_LOGIN=... SUPER_PASSWORD=... SECURE_COOKIES=1 npm start
```

| Переменная | Значение |
|---|---|
| `DATABASE_URL` | PostgreSQL; если не задана — локальный PGlite в `PGLITE_DIR` (по умолчанию `./data`) |
| `SUPER_LOGIN`, `SUPER_PASSWORD` | первый Супер-ведущий, создаётся при пустой базе |
| `PORT` | порт, по умолчанию 3000 |
| `SECURE_COOKIES=1` | включить при работе по HTTPS |
| `ANTHROPIC_API_KEY` | ключ Claude API для ИИ-помощника ведущего |
| `OPENAI_API_KEY` | необязательно: расшифровка загруженных и записанных голосовых (Claude не принимает аудио); без ключа работает только диктовка в браузере |
| `STT_MODEL` | модель расшифровки, по умолчанию `whisper-1` |
| `GOOGLE_SERVICE_ACCOUNT_JSON` | ключ технического аккаунта Google (содержимое JSON-файла) для живой Google-таблицы; или путь к файлу в `GOOGLE_SERVICE_ACCOUNT_FILE` |

## Готовые игры

В банк заведены две игры из материалов организаторов: «Развлечения: офлайн против онлайна» и «Еврологистика — глядя в будущее».
Списки ролей, стартовые счета, активы, OPEX за такт и прайс Игротехника (CAPEX) — в [docs/games/razvlecheniya.md](docs/games/razvlecheniya.md)
и [docs/games/evrologistika.md](docs/games/evrologistika.md). Данные — в `server/src/seeds/games-data.ts`.

```bash
npm run seed:games                    # создать обе игры (уже созданные пропускаются)
npm run seed:games -- --branch host   # плюс запущенное ответвление каждой игры для ведущего с логином host
npm run seed:games -- --docs ../docs/games   # пересобрать документы после правки данных
```

## Google-таблица: подключение

Банк сам пишет в Google-таблицу: листы «Переводы», «Сводка», «Мощности», «Выручка и OPEX», «Журнал активов» обновляются через несколько секунд после каждой операции. Таблица — зеркало: источник данных — банк.

Один раз для сервера:
1. Откройте [console.cloud.google.com](https://console.cloud.google.com), создайте проект.
2. «APIs & Services» → «Library» → включите **Google Sheets API**.
3. «IAM & Admin» → «Service Accounts» → «Create service account» (роль не нужна).
4. В созданном аккаунте: «Keys» → «Add key» → «JSON». Скачается файл.
5. Положите содержимое файла в переменную `GOOGLE_SERVICE_ACCOUNT_JSON` на сервере (или путь к файлу в `GOOGLE_SERVICE_ACCOUNT_FILE`) и перезапустите сервер.

Для каждой игры (ведущий, в кабинете → «Google-таблица»):
1. Создайте пустую Google-таблицу.
2. «Настройки доступа» → добавьте e-mail технического аккаунта (показан в кабинете) с правом «Редактор».
3. Вставьте ссылку на таблицу и нажмите «Подключить». Таблица появится прямо в кабинете.

Папки. Супер-ведущий задаёт общую папку (раздел «Google-таблица»), её нужно открыть техническому аккаунту как редактору; для папок в проекте Google Cloud должен быть включён **Google Drive API**.
Банк раскладывает таблицы так: `общая папка / <корневая игра> / <смена — ведущий>`. Кнопка «Создать подпапку игры» создаёт подпапку; таблицу в ней создаёт ведущий
(у технического аккаунта нет своего места на личном Диске, поэтому сам создать файл он не может; в общем диске Google Workspace — может). Таблица в подпапке
автоматически доступна банку; после подключения банк даёт ей стандартное имя и, если она лежит внутри общей папки, переносит в подпапку игры.

## Как устроено

- Все деньги двигаются только через одну функцию перевода (`server/src/transfers.ts`): транзакция,
  блокировка счетов, проверка баланса, уникальный ключ операции против двойного списания.
- Корневая игра описывает роли, стартовые балансы, юрлица и прайс; ответвления наследуют изменения корня,
  пока ведущий не изменил строку у себя.
- Балансы в кабинетах обновляются сами (Server-Sent Events).
- ИИ-помощник ведущего (`server/src/assistant.ts`, модель Claude Opus 5.5): у каждого ведущего свой чат по каждой игре.
  Читает данные игры через инструменты (счета, роли, переводы, сводка такта, статистика, правила и прайс),
  разбирает фото бумажек и готовит операции, которые проводятся только после подтверждения ведущего,
  помогает придумывать механики с расчётом CAPEX / OPEX / эффекта.
